# University collection table variants
All XLSX members from the three supplied university-collection ZIPs are accounted for in MANIFEST.json. Byte-identical copies reference one stored file. Nonidentical variants are retained under the source archive name; no version is silently promoted to a verified final dataset. These tables supplement the full collection notebooks, joined research tables and original Scopus workbooks already present.

Research matching and inferred gender labels are historical analysis outputs, not verified identity facts. No new scraping or demographic enrichment was performed.
